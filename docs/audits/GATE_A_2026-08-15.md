## Arquitectura observada

Grafo real sin ciclos:

```text
Domain (BCL)
  ↑
Application (BCL)
  ↑          ↑
Content   Infrastructure
  ↑          ↑
Presentation │
       ↑     │
       Bootstrap  ← único composition root
       ↑      ↑
Editor/Tests.EditMode   Tests.PlayMode
```

Domain no referencia `UnityEngine`; Application solo referencia Domain/BCL. Presentation no referencia Infrastructure. Solo Bootstrap conoce los concretos y su registro es tipado/interno, no un locator global. No se encontraron `FindObjectOfType`, `DontDestroyOnLoad`, singleton mutable ni listeners vivos después de shutdown. Editor y tests no entran al player.

Orden real: `MessageBus → Analytics → Ads → Purchases`; shutdown inverso. Development usa NullAnalytics/MockAds/MockPurchase solo mediante define de build; Release usa NullAnalytics/NoAds/UnavailablePurchase y oculta diagnóstico Development.
