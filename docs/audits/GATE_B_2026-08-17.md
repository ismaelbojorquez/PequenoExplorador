## Arquitectura observada

```text
Camp UI → WorldSession/SceneFlow → Explorer/Input
  → InteractionCoordinator → LearningCoordinator
  → Photography/CapturePhotoUseCase
  → Discovery → Economy + MissionCoordinator
  → AlbumQuery → CampUpgradeCoordinator
  → SaveCoordinator/checkpoints → Camp
```

- Presentation entrega intents y consume snapshots/view models; no lee JSON ni muta `PlayerProgress` directamente.
- Application coordina resultados tipados e idempotency keys; Infrastructure posee filesystem, save, thumbnails y handles Addressables.
- Bootstrap compone y secuencia lifecycle/checkpoints. Addressables conserva ownership único y no hay remote catalogs/endpoints.
- Checkpoints observados: captura/discovery, learning, activación/completion de misión/reward, compra de mejora, retorno a Camp y pause.
- Los tests cubren cancelación/unload/fallo de storage y scene flow; no se observaron escenas, listeners, RenderTextures o handles huérfanos en la evidencia automatizada.
