# Directorio de ExecPlans

Aquí viven únicamente planes reales creados bajo [`.agent/PLANS.md`](../PLANS.md). Nombre: `<fase>-<slug>.md`, en minúsculas ASCII y guiones, por ejemplo `03-project-foundation.md` cuando esa fase comience y realmente requiera plan.

No existe un ExecPlan activo en Fase 02: esta fase es un contrato documental autocontenido y acotado. [`docs/STATUS.md`](../../docs/STATUS.md) debe enlazar cualquier plan activo futuro. No crear archivos vacíos, ejemplos fingidos ni planes retroactivos.
